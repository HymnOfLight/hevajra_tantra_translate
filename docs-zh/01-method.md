# 新方法设计：经验证、证据分级的对勘法（VEC）

版本 v0.3 · 2026-09-30 · 依据《hevajra_tantra_translate 代码审查与研究价值评估》（下称"审查"，全文见 [`reference/2026-09-30-code-review.md`](reference/2026-09-30-code-review.md)）

本文回答一个问题：在审查指出"头条数字与噪声不可区分"之后，这项研究应当换用什么方法，以及 Claude Opus 5.5 在其中扮演什么角色。实施安排见 [`02-plan.md`](02-plan.md)。

设计过程：四个独立视角（方法学/统计、文献学、软件架构、LLM 测量工具）各自出方案，三位评审（数字人文会议审稿人、五年期维护者、审查作者本人视角）打分，再综合、再逐条对照审查做完整性核对。下文是综合后的结论，并已按研究者的四项决定调整（§12）。

---

## 0 为什么必须换方法

审查的结论可以压缩成一句话：**旧流水线的"信号"来自长度统计和先验参数，而不是来自内容；而且没有任何办法知道它对不对。**

| 审查发现 | 根因 | 新方法的对应 |
|---|---|---|
| 汉译"缺失率 0.184"与纯长度、随机向量两类安慰剂的结果区间重叠；只换后端，ABSENT 集合几乎不相交 | 四分之三的对齐只靠长度；PARTIAL 只按"长度不足基线一半"判定 | 状态只由**内容证据**决定（Claude 读原文给出的关系＋逐字核验的引文，或人工裁决）；长度只作描述性维度 `d_len` |
| 仓库里没有任何人工金标准对齐 | 先建模型、后谈验证 | **先验证、后度量**：盲标金标准、每次运行都算的对照组与扰动测试、预注册门控；门控不过，报告只许输出"未经验证的计数" |
| 四处原文抽查全部判错（I.7 类名略去、II.3 意义反转、II.9 并入汉第 18 品、末尾三偈汉有藏无） | 单元层与长度模型看不见这些现象；章级硬门控 | Claude 以整品为单位逐句对读，输出"反转/替换/类名略去/仅见于见证"等**关系类型**；概表只作软窗口，越界链接变成"概表诊断" |
| 人工复核写出去就回不来；证据等级永远是 C | 缺少回写通道 | 人工裁决以坐标＋指纹为键，**每次构建矩阵都重新应用**；证据等级按规则计算 |
| 品区组自助法只量了"抽到哪些品"，没量对齐误差 | 统计设计错位 | 对全经普查的量**不做**品区组自助法；用"两阶段核验"（机器阳性核验＋机器阴性分层抽检）估计并校正误判 |
| 三分分解不穷尽、以校勘本当独立见证、没有零模型、共享类被德格修订层污染 | 分解定义不严 | 分解穷尽且有 `insufficient` 类；只以**写本**为单位；以循环平移零模型报告"超额比例"；德格为唯一藏文列时标 `COWITNESS_REVISED` |
| 动机正则把"这不是审查"也算作断言审查；Qwen3 思维链泄漏 | 评分规则与模型部署缺陷 | 流水线内**任何 LLM 都不做动机归因**；过度归因实验用"逐原因立场"的盲评分器＋否定感知的词表规则＋人工锚定 |

审查对研究价值的判断也被采纳为设计约束：真正的瓶颈是**专家工时与写本数据**，自动化能省的是检索和记账。所以新方法的每一步都要回答"它省了专家多少时间、它的错误怎么被发现"。

## 1 核心原则

1. **先验证、后度量。** 任何由机器产生的比率，只有在测量工具通过预注册门控之后才会被打印：它必须在一个封存的、概率抽样的盲标测试集上达到绝对门槛，**并且**置信区间下限高于所有无内容对照组的区间上限（在同一批单元上比较）。否则报告为"描述级"，只输出标注为"未经验证的工具输出"的计数。人工核验过的计数任何时候都可以输出，因为它不依赖工具。
2. **状态来自内容证据，从不来自长度。** PARTIAL 与 ABSENT 必须有经核验的关系（Claude 的关系＋逐字通过的引文，或人工裁决）。
3. **Claude Opus 5.5 是有误差率的测量工具，不是神谕。** 冻结的提示与 schema 哈希（"工具指纹"）；严格 JSON、流水线任务不含自由文本；每个 id 与每段引文都由代码核验；每品重复 3 次；响应缓存＋审计日志，使任何已发表的数字都能离线、无密钥地逐字节重放。
4. **构造上的盲法。** 对勘调用一次只看一个参照、一个见证（不给梵文、不给大正藏脚注、不给主题标签）；主题预标只看参照文本、从不看汉文；实验评分器看不到实验条件；人工金标准、抽检、首轮核验都看不到机器结论。流水线内没有任何 LLM 做动机归因——那正是实验要研究的行为。
5. **每个数字都说明自己估计的是什么。** 估计量、总体（普查还是超总体）、适用范围、报告级别、区间覆盖了哪些误差来源都随数字一起打印。无法估计的量打印 `NOT_ESTIMABLE: <原因>`，**绝不打印 0**。
6. **以专家工时为预算的误差校正。** 罕见而重要的类别全部人工核验；常见类别分层抽样；一个后验预测插补机制服务所有估计量；主题组本身是校正分层，所以"敏感段落上误差不同"会被自动校正；仍未解决的单元给 Manski 界。
7. **坐标就是键。** 稳定 id 由见证原生坐标派生（大正藏页栏行、德格叶.行），外加文本指纹检测漂移。人工裁决在每次构建时重新应用；指纹过期的裁决列出来，绝不静默套用。
8. **工程上 KISS/SOLID：函数式内核、薄外壳。** Claude、基线、安慰剂、金标准共用一种 `Alignment` 类型，比较天然公平；只在已有两个以上实现的地方设协议（`LLMClient`、`Similarity`）；依赖只有标准库＋PyYAML，`anthropic` 为可选依赖且延迟导入；代码、注释与 `docs-zh/` 以外的文档全英文，由测试强制；所有多语种材料只放在 `data/`。

## 2 流水线

每个阶段是一个普通函数、对应一个 CLI 子命令，阶段之间通过 `runs/<UTC时间>-<git短哈希>/` 下的文件传递，没有工作流引擎。

```
fetch → ingest ─┬→ baselines（长度对照 P1、锚点 DP 基线 B0）───────────────┐
                ├→ collate（Claude T1，3 次重复）→ build（共识＋人工裁决＋金标准 → 矩阵）→ evaluate（门控）→ stats → report
                ├→ topics（Claude T3 预标 → 人工确认）─────────────────────┘
                └→ components（Claude T2，组件层，描述性）
review export / import / reveal（人工盲标与核验，任意时刻）
experiment overattribution plan / run / score（Claude T4 受试、T5 评分）
```

| 阶段 | 做什么 | 是否调用 Claude |
|---|---|---|
| `fetch` | 下载 CBETA T18n0892.xml 与 Esukhia 德格本第 80 函，记录 SHA-256 | 否 |
| `ingest` | 切分并生成稳定 id；夹注按 7 类保留为 `note` 片段；181 条大正藏脚注全部保留（其中 16 条注明东大梵本）；德格本卷末 རྫོགས་སོ 之后标为副文本，并解析三条译者题记；`{原字,校字}` 取校字并记录 26 处异文；做 G0 完整性检查 | 否 |
| `baselines` | 同一个动态规划，分别配"恒为 0 的相似度"（纯长度对照 P1）与修正后的锚点相似度（B0）；也可导入外部工具预先算好的对齐（如 MITRA-E、DharmaNexus）作同台比较 | 否 |
| `collate` | Claude T1 整品对勘，每品 3 次重复；代码核验 V1–V11 | 是 |
| `build` | 重复结果投票成共识；按"金标准 > 人工终裁 > 机器共识"的优先级生成单元格；计算证据等级；洗牌对照 P2 | 否 |
| `evaluate` | 在金标准上给 Claude 与所有对照组打分；哨兵事实核对；门控 G0–G4 | 否 |
| `perturb` | 扰动测试：错窗、删句、去否定词 | 是 |
| `topics` | Claude T3 只读参照文本做主题预标 → 导出给人确认 | 是 |
| `review` | 导出盲标/核验/抽检表格，导入人工裁决 | 否 |
| `components` | Claude T2 组件层逐槽位编码（描述性，未验证前不进入估计） | 是 |
| `stats` | 两阶段校正的患病率、Δ、分解、功效 | 否 |
| `report` | 按报告级别输出英文 `summary.md` 与 SVG（中文术语对照见 `06-outputs-glossary.md`） | 否 |

## 3 Claude Opus 5.5 在方法中的角色

### 3.1 五个任务

| 任务 | 替代旧角色 | 输入 | 输出 | 用途 |
|---|---|---|---|---|
| **T1 整品对勘器** | R1 嵌入、R2 对齐复核 | 一个参照品块（≤150 单元、相邻块重叠 10 单元）＋**完整汉文全文**（作为可缓存的静态前缀，含夹注行，不含大正藏脚注与坐标）＋"核心窗口"（概表映射的汉文品 ±1） | 每个参照单元：链接到的汉文片段、关系类型、是否极性反转、置信度、两侧逐字引文；以及仅见于汉文的片段 | **测量工具**，进入矩阵 |
| **T2 组件编码器** | R4 组件预填 | 已对齐的单元对（从片段库取全文，不再用截断到 80 字的文本） | 每个槽位（施事/动作/受事/工具/处所/数量/条件/否定情态/结果）编码为 ret/gen/sub/lit/om/add，外加极性反转标记与逐字引文 | 描述性组件剖面与"译法剖面"；在 150 对双人编码上报告逐码 P/R 之前不进入估计 |
| **T3 主题预标器** | R5 主题预标 | **只有参照文本**（函数签名强制，测试断言） | 多标签主题＋逐字线索 | 只为人工确认排序、预填；主题标签由人决定 |
| **T4 实验受试者** | R7 反事实 | 实验条目 | 解释＋最可能原因＋前提是否成立 | 过度归因实验的研究对象 |
| **T5 实验盲评分器** | 旧动机正则 | **只有**受试者的解释文本 | 对六类原因各给"断言/假设/否定/未提及"＋主原因＋动机引文 | 否定感知的结果编码，由人工锚定 |

弃用：R3 命题切分（LLM 切出的单元每次运行都会变，破坏行标识）、R6 LLM 归因（流水线内的动机归因恰恰是实验研究的偏差）、R8 记忆探针（由受试者的 `premise_ok` 字段替代）、R9 逐格说明（逐字引文＋关系码本身就是说明，自由文本会招来动机措辞）、嵌入与混合相似度（审查已证明其与随机向量不可区分）、全部 vLLM/Qwen/5090 部署。

### 3.2 关系类型（T1 的输出词表）

| 关系 | 判定 | 例 |
|---|---|---|
| `equivalent` / `paraphrase` / `expanded` | 保留（措辞不同或有增补） | — |
| `generalised` | 以上位词概括 | śvānamāṃsa → 肉 |
| `substitution` | 指称被替换 | 27b.4 སྐད་ཅིག་གསོད་པར་བྱེད ↔ 0601a03 剎那降伏 |
| `reversal` | 极性或情态翻转 | II.3 "你当杀生…" ↔ "一者不應殺害眾生…" |
| `category_name_omitted` | 列表成员保留，类名被略去或换成序数 | I.7 十二处 |
| `transliterated` | 音写不释 | — |
| `abridged` | 部分保留 | — |
| `no_counterpart` | 找不到任何对应 | — |
| 仅见于汉文：`addition` / `translator_note` / `paratext` / `belongs_elsewhere` | 汉文独有材料 | 末尾三偈 |

### 3.3 代码核验（V1–V11，全部是纯函数）

覆盖（每个参照单元恰好出现一次）、句柄存在、关系与链接一致、**引文逐字**（归一化后必须是被引片段的子串；只在异体字折叠后才匹配的标为 `quote_variant_form`）、必填引文、极性一致性（否定词只出现在一侧引文中才算"佐证"）、越窗链接转为概表诊断（II.9 → 汉第 18 品就是这样浮现的）、交叉链接只标记不删除（II.3 既是反转也是重排）、汉文侧穷尽（核心窗口内每个汉文片段要么被链接、要么列为仅见于汉文，末尾三偈由此被抓住）、块重叠一致性、音写字符比例检查。核验失败的单元不会悄悄变成 PRESENT 或 ABSENT，而是 `UNALIGNED(原因)` 并排在复核队列最前。

### 3.4 API 用法与三个技术事实

- 模型 `claude-opus-5-5`，统一用流式 `messages.stream(...).get_final_message()`；**不传** `thinking`（该模型思考恒开、无法关闭）、**不传** `temperature`（该模型不接受采样参数）、不用预填、不用工具；结构化输出用 `output_config={"effort": ..., "format": {"type": "json_schema", ...}}`，effort 显式设定（该模型默认是 medium）。
- **不可复现性**：由于不能设温度，同一请求每次结果可能不同。对策是三件事：内容寻址的响应缓存（重放逐字节一致，`--offline` 无密钥可重算）；每品 3 次重复并投票，重复间一致性按"人与人一致性"同样报告；工具指纹一变即视为新工具，须重新过门控。
- **拒绝与替换**：`stop_reason == "refusal"` 时记录类别，单元记为 `UNALIGNED(refused:<类别>)` 交人工，不自动重试。**fallback 按研究者决定：流水线任务开启、实验关闭**；但由于服务器端 fallback 对同一内容约一小时内是"粘性"的，发生替换的响应一律标记为 `substituted_model`，其单元记为 `UNALIGNED(substituted_model)`，替代模型的草案只作为给复核者的提示，**永不进入测量统计**。
- 费用估计（同步价，$4/$20 每百万 token）：T1 单次全经约 35 次调用、$15–30；含 3 次重复、effort 扫描与扰动测试的一个完整对勘周期约 $80–140；T2 约 $15；T3 约 $6；实验约 $90。合计约 $200–250（今后可加 Batches 预热缓存再省约一半，本版暂不实现）。配置里设 `budget_usd: 300` 的硬上限。**真正的约束是专家工时，不是钱。**

## 4 状态与证据等级

### 4.1 关系 → 状态（全仓库唯一推导状态的地方，长度从不参与）

| 关系 | 状态 | 结果类 | 计入"任何偏移" D_any | 计入"覆盖偏移" D_cov |
|---|---|---|---|---|
| equivalent / paraphrase / expanded | PRESENT | 无偏移 | 0 | 0 |
| transliterated（参照为真言） | PRESENT | 无偏移 | 0 | 0 |
| transliterated（参照非真言，即"以音译行遮蔽"） | PRESENT | 在场偏移 | 1 | 0 |
| generalised / substitution / category_name_omitted / reversal | PRESENT | 在场偏移 | 1 | 0 |
| abridged | PARTIAL | 部分 | 1 | 1 |
| no_counterpart | ABSENT | 缺失 | 1 | 1 |
| 未解决（未评估、被拒、截断、无效、模型被替换、核验失败、无多数） | UNALIGNED(原因) | — | 不计 | 不计 |

主结果变量默认 D_any（与德重的"省略＋改写＋音写"口径可比），D_cov 同时报告（与旧"0.184"可比）。ABSENT 与 PARTIAL **永远分开报告**。

### 4.2 共识与等级

三次重复按"结果类"投票，≥2/3 为多数；无多数 → `UNALIGNED(no_majority)`。等级是**抽检的分层变量**，不是假定的准确率，各等级的实际准确率由抽检报告：

| 等级 | 规则 |
|---|---|
| A | 指纹匹配的人工裁决（金标准或核验/抽检/解决的终裁） |
| B | 3/3 重复一致，且全部核验通过 |
| C | 2/3 多数，或带任何非致命标记（异体引文、交叉、越窗、极性未佐证、块重叠不一致、疑似"说明被音写"） |
| X | 核验致命失败或无多数 → UNALIGNED，排在复核最前 |

构建单元格的优先级：金标准 > 指纹匹配的人工终裁 > Claude 共识；基线永不进入矩阵。

## 5 验证

### 5.1 金标准（只接受盲标）

| 集合 | 选法 | 规模 | 用途 | 工时 |
|---|---|---|---|---|
| 开发集 | 目的性：I.1 全品；I.7 全品；II.3 中 17b.6 前后各 20 单元；II.9 第 1–56 单元对汉第 18 品；II.11 尾部＋II.12（合并品边界） | 约 450 单元 | 提示词开发、effort 扫描、扰动测试；在调用 Claude 之前先给出基线的 P/R 报告。**从不用于门控** | 约 18 小时 |
| 测试窗 | 概率抽样：12 个 25 单元的连续窗，品按篇幅比例抽、起点均匀，排除开发区；随机种子写进预注册 | 300 单元 | 门控 G1 | 约 15 小时 |
| 第二标注者 | 12 窗中的 4 窗 | 100 单元 | 人与人一致性，作为 G1 的天花板 | 约 5 小时 |

之所以测试集要随机抽而不是用审查推荐的那几品：挑出来的难品得到的误差率不能外推到全经；它们留作开发集与哨兵。标注者在"辅助复核"阶段看过机器结论后给出的裁决，进入矩阵算 A 级，但**永远不作为 G1 的金标准**（否则是循环论证）。

### 5.2 对照组与扰动（每次 `evaluate` 都算，不能关）

| 对照 | 定义 | 目的 |
|---|---|---|
| P1 纯长度 | 相似度恒为 0 的同一动态规划 | 主要的无内容竞争者 |

### 6.2 两阶段估计（一个机制服务所有估计量）

- 机器阳性里的罕见要类（无对应、反转、替换、类名略去、越窗、仅见于汉文、X 级）**全部**人工核验；常见类（部分、概括、散文音写）按关系×主题组分层抽样，总量受预注册上限约束；但每个抽样层至少抽 min(该层可抽单元数, 20)，即使普查类已超过上限也是如此（否则该层没有第二阶段裁决、无法估计）。落在夹注片段上的"仅见于汉文"声明不进入核验计划。
- 机器阴性按"等级（B/C）×主题组（敏感/非敏感）"分 4 层盲抽检，每层至少 40、C 级加倍。
- 每层以 Dirichlet(观测计数 + ½) 为后验，对未核验单元做后验预测插补，得到 500 套完整状态向量；每个估计量在每套上计算，取 2.5–97.5 百分位为区间。普查层不贡献不确定性。
- 同一套代码改用"盲判"列即可得到"自动化偏差"的敏感性估计，与改判率一起报告。
- 由于主题组是分层变量，敏感段落用敏感段落自己的误差率插补——"模型在敏感段落上更容易看见缺失"这类差异误差被构造性地校正。

### 6.3 Δ（E4）

分层风险差 Δ = Σ_c w_c (r̄_{c,敏感} − r̄_{c,中性}) / Σ_c w_c，分层 c = 品×参照长度的秩三分位（按并列取中位秩：f = (更短的单元数 + 等长单元数/2)/n，f < 1/3 为 t1，< 2/3 为 t2，否则 t3；真实文本中 3042 个单元有 2503 个是 7 音节，按数值切点会使 t2 为空，按中位秩则 7 音节单元自成 t2），w_c = n_s·n_n/(n_s+n_n)。每套插补同时有放回地重抽品。层内置换主题标签 2,000 次得 p 值。零结果按 TOST 报告为"在 ±MDE 内等价"，不写成"没有效应"。旧的贪心 1:1 匹配保留为稳健性检查。排除叙述框架句、真言对照、整表一致变化的单元与脱文。

模拟功效（示意）：最小可检测效应（80% 功效）约 0.07–0.10；0.03 的 Δ 在这部经里测不出来。冻结预注册前，会用**人工**主题标签与开发集误差率重算，并把真实 MDE 写进预注册。

### 6.4 分解（E3）

对每个 D=1 的单元按顺序取第一个匹配的类，穷尽且代码断言总和：

1. `attested_vorlage`：宿主片段上有"底本陈述"类夹注（0592a27"七者、八者，梵本元闕"）。另设 `attested_translator` 记录"替换说明"类夹注（0589a09、0589a13，是配料替换的说明），它属于译者一侧的证据，**不减少残余**。在以德格本为参照时，德格本同样没有 melāpaka 地名表，所以目前没有任何偏移单元适用这两类，只作描述性清单报告。
2. `vorlage_ms`：至少一个有信息的梵文**写本**缺或异（校勘本不算独立见证）。
3. `shared`：共同见证也偏移；只有德格本时标 `shared_revised`，φ_S 为下界、残余为上界。
4. `residual`。
5. `insufficient`：有信息写本不足 2 个，或共同见证不可计。

零模型：共享类同时报告观测数 O、独立假设下的期望 E = Σ p·q 与 O − E；φ_V = (a_V − b_V)/(1 − b_V)，a_V、b_V 分别为偏移与未偏移单元中"有写本缺此单元"的比例。进入分解的偏移单元要么全部人工核验，要么把未核验的"共享"按"非共享"处理给出界。品内循环平移零模型与各写本优势比（"哪个写本与汉译底本同源"的谱系诊断）等有了写本数据再实现。当前没有写本列、参照即德格本，E3 打印 `NOT_ESTIMABLE`，并附夹注证据的描述性清单。

## 7 人工复核

全部复核用表格完成（CSV，带 BOM 以便电子表格打开），不需要专门软件：

- **盲标 → 揭示**：先导出不含任何机器结论的盲表，导入盲判；再导出揭示表（附机器关系、链接、引文、等级），导入终裁。两次判断都保存，改判率即自动化偏差指标。

## 8 过度归因实验 v2

问题：当给出的证据显示某处汉文缺文可由源文本或共享传统解释时，Claude 是否仍断言译者动机？敏感内容上是否更强？

- **设计**：内容（敏感/中性，条目间）× 证据（条目内：E0 无证据；EP 等长安慰剂句"此段在所用刊本中位于汉译第三卷"；EW 见证事实，两种说法各半——"梵文写本校勘显示两个写本同样缺此段"/"另一部独立译自梵文的译本同样缺此段"）；每条件重复 3 次；条件顺序随机；**fallback 关闭**；结论只对 `claude-opus-5-5` 在该实验日期成立。
- **条目**：实验作为独立的早期轨道，不必等全经主题确认完成：从约 300 个经人工主题标注的候选单元中取 60 敏感＋60 中性的偈长段落，另有 10＋10 预实验；中性与敏感按同品或邻品、长度 ±25% 配对。`omission_origin` 记录为"真实缺文（人工核实）"或"构造缺文（从展示的汉文上下文中删去对应句）"。有文献记载真值的只有 1 例（0592a27"梵本元闕"；另两条夹注是配料替换说明，不是缺文），只做定性分析。条目库只入库坐标，文本运行时从 `data/raw/` 重建。
- **受试（T4）**：effort 用 medium（即 API 默认值，代表一般研究者实际得到的行为）；系统提示不含任何动机词（测试强制）；输出解释（≤120 词）、最可能原因（七选一）、前提是否成立（识别模型"记得汉文其实有这段"）。
- 提示词从不要求模型"展示或解释它的推理过程"（Opus 5.5 有 `reasoning_extraction` 类安全分类器）；解释字段针对的是这段文字，而不是模型的思考。
- **评分（T5）**：只看解释文本，逐原因给"断言/假设/否定/未提及"，这正是审查指出的"否认动机也被算作断言"的修正；动机引文须为子串。另有否定感知的词表规则作透明基线（单元测试覆盖"This is not censorship""並非刪略"）。两位人工编码者盲编 150 条；评分器对人工共识 κ ≥ 0.80 才作为主结果，否则用两阶段校正。
- **假设**：H1 敏感组中有证据时动机断言率下降；H2 无证据时敏感 > 中性；H3（交互）在每组 60 条时功效约 0.56，定为探索性。条目为分析单位，配对条目自助法＋符号翻转置换，Holm 校正。拒绝单列为结果，并做"全算/全不算"两种界。
- 规模：约 1,080 次受试＋约 1,300 次评分调用，同步约 $90。
