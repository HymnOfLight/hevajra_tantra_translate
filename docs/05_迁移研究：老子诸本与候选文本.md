# 迁移研究：《老子》诸本，以及更多古代文本候选

版本 v0.1 · 与 `hevajra_matrix/transfer/sinitic.py`、`data/transfer/laozi/` 同步

---

## 0 为什么要做迁移

docs/03 §7 提出一个可检验的命题：见证矩阵法从 W3（对齐）起与语言无关，换文本只需改 W0–W2 与锚点。命题要靠实际迁移来证伪或证实，而且被迁移的文本应当**在关键假设上与《喜金刚》相反**，这样才测得出方法的边界。《老子》正好相反于《喜金刚》：

| | 《喜金刚》| 《老子》|
|---|---|---|
| 参照 | 有源语言文本（梵文，多个校勘本）| **没有**源文本；最早见证（郭店）本身是选编本 |
| 见证语言 | 跨语言（梵 → 藏 / 汉 / 西夏 / 蒙）| **同语言**（汉语，跨 500 年书写系统变化）|
| 对齐信号 | 锚点（术语/专名/数词）＋长度 | 字符 n-gram（经异文归一）|
| 主要偏移 | 覆盖、篇幅、音译、组件 | **章序**、异文层次、虚词、句序 |
| "金标准是分布" | 梵文校勘本之间的 σ_S | σ_S 就是**全部**：见证间离散度即研究对象 |
| 动机归因的诱惑 | "译者自我审查" | "汉代改字避讳""道家学派改造"——同一种过度归因 |

如果同一套矩阵、同一组维度、同一份分解与统计代码在《老子》上跑通并给出有文献学意义的读数，方法论文的"可迁移"主张就有了第一个反向证据。`transfer/sinitic.py` 实际改动的模块：切分（`parse_witness_file`）、相似度（`CharNgramBackend`）、一个新维度（`d_lex`）、一个后处理（`reorder_pass`）、章序度量（`order_deviation`）；`metrics.py`（分解、自助法、距离、UPGMA、Kendall τ）一行未改；`matrix.py` 只加了 `d_lex` 列与可配置的章列表，`report.py` 只改为读取该章列表，`ids.py` 增加了可注册的分部前缀 `L`。这几处 diff 就是方法论文要报告的"迁移成本"。

## 1 见证（列）

`data/transfer/laozi/witnesses.yaml`，14 列，四层：

- **出土本（primary）**：郭店甲、乙、丙组（约前 300，选编本）；马王堆甲、乙本（前 200 前后，完整本，德经在前）；北大汉简（西汉中期，完整本，分上下经）。
- **传世校本（edition）**：王弼本（参照坐标）、河上公本、傅奕古本。

独立性判断与《喜金刚》同构：郭店三组、马王堆两本是**独立同源写本**（可互为 cowitness）；王弼与河上公属同一传世系统（**derived**），两者之差是 σ_S 的下界；想尔注是**有立场的修订层**（revised），对应德格本的 gZhon nu dpal 修订层。

## 2 参照与行

### 2.1 参照 = 坐标系，不是金标准

参照列取王弼本 81 章的章/句坐标，`reference_grade = "coordinate_only"`。这个等级比 `provisional` 更弱：`provisional` 说"暂用一个见证替代金标准"，`coordinate_only` 说"根本没有金标准，参照只提供行号"。因此：

- 所有"缺失率"读作"相对通行本坐标的缺失"，其反向（通行本相对郭店的"增写"）由孤儿行承载，二者对称；
- 三分分解的 Vorlage 项恒为 0，退化为"与另一早期见证共享 / 残余"两项；
- 报告的主量是见证间距离矩阵与 UPGMA 树（σ_S 的结构），而非任何一列的"偏移大小"。

81 章分章本身是汉以后的：分章数历代有 64/68/72/81 诸说，郭店甲组对第 64 章前后两半分抄于两处、丙组又抄一次后半。所以章只用作对齐的**门控**，章边界的分歧本身是可测量的结构信号（半章标记 `#64下` 在 `extra.half` 中保留）。

### 2.2 行

`L.19.p03`：第 19 章第 3 句（按 `。？！，；：、` 切分，标点不进入相似度）。全书约 1,100–1,300 行，与《喜金刚》同量级。

## 3 偏移向量的变化

| 维度 | 《喜金刚》定义 | 《老子》上的解释 |
|---|---|---|
| `d_cov` | 单元在见证中是否存在 | 同；选编本未收之章一律 `NA`（**不是** `ABSENT`）；残字 □ 占比 ≥ 50% 的句 → `LACUNA` |
| `d_len` | 篇幅对数残差 | 马王堆本句末"也"字、傅奕本虚词偏多 → 每见证单列基线（已自动按见证中位数校准）|
| `d_lit` | 音译密度 | 无意义，恒 0（保留列以维持表结构）|
| `d_ord` | 章内位序位移 | 单调 DP 看不见句序倒换；`reorder_pass` 对低相似度格在同章内做非单调重连，命中则 `bead=1:1*` 并给出位移量（郭店第 19 章"絕巧棄利、盜賊亡有"前移即由此检出）|
| `d_split` | n:m 结构 | 同 |
| **`d_lex`（新）** | — | 1 − Dice(归一后字符 1/2-gram)；`alignment_review.csv` 同时给 `d_lex_raw` 与 `variants_explained`（如 `無=亡 常=恆`），使"可由避讳/通假解释的差异"与"真正的异文"分开——这是三分分解思想在同语言场景的直接对应 |
| 章序（L1 新量）| 品的合并/缺失 | `chapter_order.csv`：对通行本章序的 Kendall τ 距离＋"德在道前"比例 |

`variants.yaml` 归一表按类别标注（避讳 / 通假 / 异体 / 虚词），虚词类默认**不归一**（弗/不、于/於、句末"也"是汉语史信号），有争议的读法（絕偽棄詐 / 絕為棄慮）不归一而进入 `d_lex`。归一表本身要预注册；使用严式释文时归一表须相应扩充并声明。

## 4 可证伪的预期读数

1. **σ_S 的分层**：距离矩阵中 王弼–河上公 < 马王堆甲–乙 < 郭店–马王堆 < 郭店–王弼；若不成立（例如河上公与马王堆更近），是关于传世系统来源的实质发现。
2. **避讳层可分离**：马王堆乙本对通行本的 `d_lex_raw − d_lex` 之和，绝大部分由 恆→常、邦→國 两组贡献；甲本 邦 字不避而乙本避，两本的 `variants_explained` 分布应当不同（这是断代证据的数值化）。
3. **章序**：马王堆两本 τ 距离 ≈ 0.5–0.7（德在道前）＋局部倒置（24→22、41→40）；郭店三组 τ 各不相同且与马王堆不同；北大简接近马王堆。
4. **"缺"的方向**：郭店对通行本的 `ABSENT` 主要落在通行本的解释性/递进句（如第 64 章"民之從事，常於幾成而敗之"），孤儿行（郭店独有）少——支持"通行本增写"多于"郭店删略"。这一条**只能报告为分布，不做动机归因**（与《喜金刚》的规则完全相同）。
5. **想尔注**：`d_lex` 在与"道/王/生"相关的句上系统性高于其他句（S.6825 的改字），且与河上公的 cowitness 共享率低——一个"有立场修订层"的可测指纹，可与德格本修订层的读数并列讨论。

## 5 LLM 在《老子》上的角色

与 docs/04 的 R1–R9 相同，只是语言变为单一的古汉语，5090 上的 Qwen3-32B 对先秦汉语的阅读能力显著优于对藏文：

- R1：`CharNgramBackend` 已够用作 B0；bge-m3 / Qwen3-Embedding 做 B1 对比，看嵌入是否能跨过书写系统差异（宽式释文下预计收益有限，严式释文下可能显著）。
- R2：对 `1:1*` 与低相似度 1:1 格出裁决——"是异文还是不同句"。
- R4：组件抽取在同语言上可直接做 L3；"絕聖棄智 / 絕智棄辯"的差异会落在 `patient` 槽位，是组件层比 `d_lex` 更细的读数。
- R6/R7：反事实实验的"第二见证事实"改为"马王堆本亦作某某"，测模型断言"避讳改字""学派改造"的比率。
- R8：《老子》全文与所有主要注本几乎必然在预训练语料中，记忆率预计接近 1——这使《老子》成为**污染上界**的天然对照组，与《喜金刚》（污染率待测）并列报告。

## 6 更多候选文本

候选需同时满足：≥ 3 个可独立的见证；有一个可作坐标系的参照；存在电子文本且许可允许本地处理；有"过度归因动机"的既有争论（这样弃判设计才有用武之地）。按参照类型分组：

### 6.1 有源语言、跨语言（与《喜金刚》同构，直接复用锚点流水线）

| 文本 | 见证 | 参照 | 亮点 | 主要阻碍 |
|---|---|---|---|---|
| 《密集》Guhyasamāja | 梵（Matsunaga 1978）；藏 Toh 442–443；汉 T0885（施护）；敦煌 IOL Tib J 438 | 梵 | 与德重 2026 的对象重合 → 只作**外部复现集**，不作主文本 | 与已发表工作撞车风险最高 |
| 《金刚经》六译 | 梵（Conze / Harrison–Watanabe 吉尔吉特本）；藏；汉：鸠摩罗什、菩提流支、真谛、笈多、玄奘、义净 | 梵 | 六个汉译跨 300 年，翻译规范变迁本身可测；篇幅小（一周可全量标注）| 梵文写本少 |
| 《心经》 | 梵（大本/小本）；藏；汉 7 译；西夏；蒙 | 梵 | 极短，可做全部维度的教学样例 | 太短，统计弱 |
| 《维摩经》 | 梵（大正大学 2004 波塔拉宫本）；藏；汉：支谦、罗什、玄奘 | 梵 | 梵本晚出而汉译早，Vorlage 方向反转 | — |
| 《法华经》 | 梵（Kern–Nanjio；吉尔吉特、中亚写本群）；藏；汉：竺法护、罗什、阇那崛多 | 梵（多本）| 梵文写本极多 → σ_S 大，"金标准是分布"最典型 | 规模大 |
| 《无量寿经》五译 | 梵；藏；汉 5 译 | 梵 | 五译篇幅差异巨大（d_len 极端）| 梵本与任何汉译都不对应 |
| 巴利尼柯耶 vs 汉译阿含 | 巴利；汉：《杂阿含》《中阿含》等；藏残本；梵残本 | **无单一参照**（巴利只是另一见证）| 对称设计：两侧都是译/传本 | 对应表（Akanuma）本身有争议 |
| 七十士译本 | 希伯来马所拉本；库姆兰；LXX 诸本；撒玛利亚五经 | 希伯来 | CATSS 平行数据库现成；"= / =?" 可直接映射到三分分解 | 领域外，需合作者 |
| 盖伦 | 希腊；叙利亚（Ḥunayn 之前/之后）；阿拉伯 | 希腊 | 叙→阿的派生链检验 derived 处理 | 电子文本分散 |

### 6.2 无源语言、同语言多见证（与《老子》同构，复用 `transfer/sinitic.py`）

| 文本 | 见证 | 亮点 |
|---|---|---|
| 《论语》 | 定州汉简（前 55）；平壤贞柏洞汉简；敦煌唐写本；何晏集解本；皇侃义疏本；朱熹本 | 章序稳定而字词异文多 → `d_lex` 主导，与《老子》章序主导互补 |
| 《周易》 | 马王堆帛书（卦序完全不同）；阜阳汉简；上博楚简；王弼本；熹平石经残 | 卦序 τ 距离是极端案例 |
| 《诗经》 | 安大简（国风，顺序与异文）；阜阳汉简；熹平石经；毛诗；三家诗辑佚 | 篇序 + 用字，双信号 |
| 《孙子》 | 银雀山汉简；十一家注本；武经七书本 | 篇幅小，可全量 |
| 《缁衣》 | 郭店；上博；《礼记》 | 三本章序各异且引诗不同——小而精的章序样例 |
| 《文子》 | 定州汉简 vs 今本 | 真伪之争 → 派生/独立判定的试金石 |
| 《尚书》 | 清华简（《尹诰》《傅说之命》等）vs 今文 vs 伪古文 | "伪古文"是有定论的派生层，可作方法的正例校验 |

### 6.3 选择建议

第一轮迁移只做两个：**《老子》**（本文件，同语言、章序、无金标准）与**《金刚经》六译**（跨语言、小规模、多汉译）。二者与《喜金刚》共同覆盖方法论的三个象限（有金标准跨语言 / 无金标准同语言 / 有金标准多目标语），且都能在现有代码上以"改 W0–W2"的方式完成——方法论文要报告的正是每次迁移实际改动的行数。

## 7 运行

```bash
# 研究者自备文本放到 data/transfer/laozi/texts/<id>.txt（格式见该目录 README）
python -m hevajra_matrix transfer --config data/transfer/laozi --texts data/transfer/laozi/texts --out out/laozi
# 无文本时可用测试夹具（三章示例，非学术释文）验证流水线
python -m hevajra_matrix transfer --texts tests/fixtures/laozi --out /tmp/laozi_demo
```
