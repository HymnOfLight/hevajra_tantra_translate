# 《喜金刚本续》多见证偏移矩阵：研究设计与独创性定位

版本 v0.1 · 2026-09-30

本文是项目的总纲。它回答三个问题：我们到底测什么、为什么这不是德重弘志（2026）及其待刊《喜金刚》研究的重复、以及评估文（"宋代密续汉藏梵对读方案：新颖性、可行性与价值评估"，下称《评估》）提出的十项修改建议如何被吸收或有意不采纳。

## 0 一句话定位

> 以梵文《喜金刚本续》为参照，把它在六种语言、十余种见证中的每一次传抄与翻译都放进同一张矩阵，用**与动机无关的、可机械复算的偏移向量**度量每个见证的"漂移"，并把漂移分解为"可由已知梵文异读解释的部分"和"残余部分"。宋代汉译只是这张矩阵中的一列，而不是研究对象本身。

这与德重弘志的工作在对象、单位、度量、统计和产出五个层面都不同（§2）。

## 1 为什么是《喜金刚》，为什么现在

《评估》建议主体缩为《密集》（T0885）＋《无二平等》（T0887），并把《喜金刚》（T0892）降为迁移测试，理由是德重已在 2026-09-04 报告其"自主规制"。我们**有意不采纳**这一建议，改为以《喜金刚》为唯一主文本、做全文普查，理由如下：

1. **见证密度最高**。《喜金刚》是唯一同时具备以下条件的宋译无上瑜伽续：多种梵文校勘本（Snellgrove 1959、Tripathi–Negi 2001、Farrow–Menon 1992、Conlon 2022）与写本群；藏译且藏译本身有可识别的修订层（德格本题记明言经贡译师童祥补阙订正）；宋译（1054–55）；西夏时期汉译与明抄本汉译（译自藏文，待核）；西夏文、蒙文派生译本；两部梵文注疏（Yogaratnamālā、Muktāvalī）逐偈引出根本续；84000 英译（2025）。这使"见证矩阵"有足够多的列才能显示结构。
2. **篇幅适合普查**。约 750 偈（含散文命题约 1,000–1,300 单元），德格本 5,800 个 shad 分隔段、汉文约 21 万字节 XML。《评估》§4.3 指出小部作品抽样配额会超过可用窗口——对《喜金刚》正确做法就是全文普查，抽样统计问题随之消失。
3. **同源双译**。藏译（约 1040 年代）与宋译（1054–55）相隔约十年、各自直接译自梵文。这是研究"同一源文本在两个翻译文化中同时落地"的近乎理想的自然实验；《密集》的藏译与宋译相隔更远且藏文有敦煌早期层，条件反而更混杂。
4. **德重的《喜金刚》研究是资源，不是障碍**。他的方法是逐偈人工归类"自主规制"（8 类内容 × 3 种手法）。这是一个**一维、二值、以动机命名的**标签。我们的矩阵在他的标签之外测量的是连续的、多维的、不指认动机的偏移，并且同时对藏译、对梵文校勘本之间、对派生译本做同样的测量。他的清单刊出后，恰好是我们省略/替换检测的外部召回验证集（`data/witnesses.yaml` → `external_replication_sets`）。

## 2 与德重弘志（2026 及待刊）的区分：五个层面

| 层面 | 德重 2026（《密集》）及其《喜金刚》报告 | 本项目 |
|---|---|---|
| **对象** | 汉译一种见证 vs 一种梵文校勘本（松长 1978；《喜金刚》推定用 Snellgrove） | ≥ 10 列见证 × 梵文"金标准分布"（≥ 3 种校勘本＋写本异读）。汉译是一列；藏译、藏译修订层、派生译本同样被测量 |
| **单位** | 偈颂（散文不计入统计） | 偈颂 **和** 散文命题；每单元再拆为语义组件（行为者/动作/受事/工具/否定/条件/数量/结果） |
| **度量** | 二值"是否自主规制"＋内容类别（性/女性/肉食/…）＋手法（省略/改写/音写） | 连续偏移向量 \(\mathbf{d}=(d_{cov}, d_{len}, d_{lit}, d_{ord}, d_{split}, \mathbf{d}_{comp})\)，与主题无关地对全部单元计算；主题只作为事后的分层变量 |
| **归因** | 直接命名动机（"戒律或社会伦理"、"对未入门者保密"） | 偏移分解为 **Vorlage 可解释部分**（存在某一梵文见证与汉译一致）、**共享偏移**（藏译同样偏移）、**残余**；动机不作标签，只在残余集中、匹配对照后作为竞争假设讨论 |
| **统计与产出** | 计数与百分比（275/250 偈，23%）；例证列表 | 全文普查；匹配中性对照；按章区组自助法区间；见证间距离矩阵与聚类；可复算的公开矩阵（坐标＋标签，不含受限文本）；流水线代码 |

三个只有本项目才能回答、德重框架无法回答的问题：

- **Q1 汉译的偏移中有多少能被现存梵文异读解释？** 需要多列梵文见证，德重只用一本。Isaacson 2022 已证明 T0892 末尾三偈与部分写本相合而藏译无——这类现象在全经中占多大比例，是本项目的核心测量。
- **Q2 藏译偏移与汉译偏移的几何关系是什么？** 若两者在同一单元上同向偏移，"Vorlage 差异"或"注疏传统"是比"汉地伦理"更节省的解释。德重框架下藏译不被测量。
- **Q3 同一目标语言、不同来源与时代的汉译（宋译 vs 西夏时期译 vs 明译）偏移剖面是否不同？** 若译自藏文的明译保留了宋译弱化的内容，则"汉语文化环境"这一解释被削弱，"宋代译场制度"被加强。这是分离两种机制的唯一设计。

## 3 对《评估》十项建议的处置

| # | 《评估》建议 | 处置 | 说明 |
|---|---|---|---|
| 1 | 改正 T0892"略出"注的解释，删除"摘出本"前提 | **采纳** | 已在 `witnesses.yaml` 与 `chapters.yaml` 写明：夹注对应藏文卷末题记（三十一/三十二之差另立行），整品缺失只能由逐偈对齐确定；程序不设"摘出界外" |
| 2 | 主体缩为 A＋B，C 只做迁移测试 | **不采纳，反向** | 见 §1。C 做全文普查；A、B 降为未来的迁移测试对象（方法论通用性验证） |
| 3 | E3 前加显式"证据是否足以支持任何归因"判定 | **采纳并机械化** | `attribution.py` 中 `evidence_gate()`：按见证覆盖模式（梵文各列在该单元是否有文、藏译是否有文、是否处于写本脱叶）先判可归因性，不足则弃判；正确弃判单列计分 |
| 4 | 加做 LLM 过度归因动机的反事实实验 | **采纳** | `attribution.py` → `CounterfactualHarness`：固定汉文缺文，切换"梵/藏第二见证是否也缺"，测 LLM 断言"审查"的比率 |
| 5 | 与德重联系，把抢先风险变成资源 | **采纳** | 其清单入外部复现集；论文中明引其《喜金刚》报告；不以其结论为新发现 |
| 6 | 机制假设扩为四项竞争假设 | **采纳并加一项** | 戒律/正统性、朝廷与润文官审核、密教秘密性惯例、理解难度，＋**Vorlage 传本差异**作为第五项（在本项目中它是可测量的，不只是假设） |
| 7 | 统一两份 PDF 与工作表；从藏/梵侧抽样；汉文直接对藏/梵 | **采纳** | 单一文本、全文普查，不存在抽样侧问题；行标识用梵文偈号；英译只作 pivot；"委婉"并入"替换" |
| 8 | 先算抽样框再定配额 | **消解** | 普查无配额 |
| 9 | 补齐引文 | **采纳** | 见 §7 文献清单；未核实项一律标"待核" |
| 10 | 许可写进数据管理计划 | **采纳** | §6 |

《评估》§4.5 关于"A 级证据不等于证明"、"标注者预期偏差"两点直接塑造了度量设计：偏移向量由组件在场/缺席**机械推导**，标注员不做整体"是否弱化"判断；"梵有汉无"在矩阵中只是 \(d_{cov}\) 的一个取值，其解释由分解式给出。

## 4 研究问题与可证伪结论

**RQ1（结构）** 各见证在章、偈、命题三个粒度上与梵文金标准的对应关系如何？汉译 20 品与梵藏 23 品的 3 品差额来自缺失、合并还是重排？
*可证伪形式*：章级对应表中每一格的 status 只能是 verified / absent / merged 之一，由逐偈对齐给出，并由两位文献学者签署。

**RQ2（偏移几何）** 各见证的偏移剖面（按章 × 按偏移维度）是否可区分？派生见证（西夏文、蒙文、明译）的偏移是否近似等于其来源列的偏移（"派生不增偏移"假设）？
*可证伪形式*：见证间距离矩阵的层次聚类应把派生见证与其来源聚在一起；若明译与宋译聚在一起而非与藏译，则"来源语言决定偏移"假设被否定。

**RQ3（分解）** 汉译偏移中，Vorlage 可解释、与藏译共享、残余三部分各占多少？残余是否在事先定义的敏感主题上集中？
*可证伪形式*：\(\Delta = R_{sens} - R_{neut}\)（残余偏移率之差，匹配对照后，章区组自助法 95% 区间）。若区间含零，接受零结果并照实发表。

**RQ4（藏译修订层）** 德格本中可归于童祥修订的部分（与其他甘珠尔比对）是否改变了藏译相对梵文的偏移？
*可证伪形式*：修订段与非修订段的 \(d_{cov}\) 分布比较。

**RQ5（方法）** 加入"金标准分布"与第二见证后，自动归因系统的弃判是否更校准（选择性风险–覆盖曲线）？LLM 在缺少第二见证信息时是否系统性过度归因动机？
*可证伪形式*：反事实实验中"审查"断言率在两种条件下的差值及区间。

不做的事：不估计"宋代译场总体删改率"；不从统计关联断言"儒家伦理"；不以任何单一校勘本作为唯一真值。

## 5 工作包与关口

| 阶段 | 交付 | 关口 |
|---|---|---|
| **WP0 资源与许可** | 各见证电子文本入库（受限文本仅本地）；SHA-256；许可表 | 梵文至少两种校勘本可用，否则金标准降为"单本＋藏译"并在所有输出打 `reference_grade=provisional` |
| **WP1 章级同本系** | `chapters.yaml` 全部格位由 proposed → verified/absent/merged | G0：两位文献学者签署 |
| **WP2 单元切分与行标识** | 梵文按 Snellgrove 偈号切单元；散文按命题切；藏、汉切段并给坐标 | 单元数与偈数核对 |
| **WP3 对齐** | B0（锚点＋DP＋NULL）→ 可选嵌入后端；人工修正全部 NULL 与 n:m | 对齐经人工复核；NULL 召回抽检 |
| **WP4 组件标注** | 每单元语义组件在各见证中的在场/缺席/替换/音译；双人盲标；组件级 α | α ≥ 0.67 方进入统计 |
| **WP5 矩阵与度量** | 长表 + 宽表 + 见证距离矩阵 + 热图 | 复算脚本一键重跑 |
| **WP6 分解与统计** | Vorlage/共享/残余分解；匹配对照；区间 | 预注册后解封 |
| **WP7 归因与 LLM 实验** | 证据充分性门 → 归因/弃判；反事实实验 | 弃判校准报告 |
| **WP8 写作** | 方法论文（NLP4DH / LT4HALA / TACL 或 Findings）＋文献学论文（分投） | 两篇的证据标准分开 |
| **WP9 迁移** | 《老子》诸本（同语言、无金标准）与《金刚经》六译（多目标语）上复跑流水线，报告实际改动行数 | 方法论文的可迁移性主张有反向证据（docs/05）|

WP3、WP4、WP6、WP7 各含本地开源大模型的子任务（单卡 5090 上的 Qwen3 / Gemma 3 / MITRA；角色 R1–R9、机械约束与评估门槛见 docs/04）；模型输出一律进派生层，与人工标注走同一条证据门。

人力瓶颈与《评估》判断一致：能读藏文与梵文并有固定工时的标注员。普查方案下的工时：约 1,200 单元 × 2 人 × 15–25 分钟 ≈ 600–1,000 小时，不含梵文专家复核。若第 3 个月仍无固定藏文标注员，退路是只做 WP0–WP3＋WP5 中不依赖组件标注的维度（\(d_{cov}, d_{len}, d_{lit}, d_{ord}, d_{split}\)），仍能产出完整的结构层矩阵。

## 6 数据、许可与发布边界

- **CBETA**（T0892）：CC BY-NC-SA 4.0，可随坐标发布短引文。
- **德格甘珠尔**（Esukhia）：许可待核；发布坐标（叶.行）而非全文。
- **梵文校勘本**：均受版权保护；仓库不含文本，只含偈号坐标。研究者自备文本放入 `data/reference/`（已 .gitignore）。
- **84000 英译**：CC BY-NC-ND；不发布派生片段。
- **MITRA / 嵌入模型**：许可不明；只作可选后端，不与 CBETA 文本合并发布。
- **公开矩阵**：只含坐标、标签、数值与短引文（≤ 合理引用长度），不含任何见证全文。
