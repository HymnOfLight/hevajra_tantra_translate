# 见证矩阵与偏移度量：形式定义

版本 v0.1 · 与 `hevajra_matrix/` 代码同步

---

## 1 矩阵的三层结构

矩阵不是一张表，而是三张共用行、列标识的表，粒度由粗到细。

| 层 | 行 | 列 | 单元格内容 | 数据来源 |
|---|---|---|---|---|
| **L1 结构层** | 梵文金标准的品（23 行）| 见证 | 存在/缺失/合并、篇幅比、品序位置 | `chapters.yaml` ＋ 自动切分 |
| **L2 单元层** | 梵文单元（偈颂或散文命题，约 1,000–1,300 行）＋ 见证独有材料的"孤儿行" | 见证 | 状态、坐标、n:m 结构、偏移向量、证据等级 | 对齐（自动＋人工修正）|
| **L3 组件层** | 单元 × 语义组件（行为者/动作/受事/工具/否定/条件/数量/结果）| 见证 | 组件在该见证中的呈现方式 | 双人盲标 |

L3 向上聚合得到 L2 的 \(\mathbf{d}_{comp}\)；L2 向上聚合得到 L1 的篇幅与覆盖。没有 L3 标注时，L2 仍可由自动对齐完整填出（结构维度），只是 \(\mathbf{d}_{comp}\) 为空。

### 1.1 行标识

- 偈颂：`I.5.12`（Snellgrove 分部.品.偈）。
- 偈颂内半偈：`I.5.12a` / `I.5.12b`（仅当见证在半偈边界断开时使用）。
- 散文命题：`I.1.p03`（品内散文按命题顺序编号，命题切分规则见 §1.3）。
- 见证独有材料（"孤儿行"）：`+zh_T0892_song:0594c15-0594c17`，即以见证 id 与坐标命名，行首 `+`。孤儿行在梵文列上取值 `ABSENT`，是"增写"现象的载体。

### 1.2 列标识

即 `data/witnesses.yaml` 中的 `id`。列带元数据：语言、来源语言、年代、独立性（independent / derived / revised）、层（primary / edition / indirect / pivot）。**pivot 层不进入任何偏移统计**。

### 1.3 单元切分规则（命题）

散文按"一个谓词及其论元"切；并列谓词共享主语时各成一命题；条件句（若…则…）作一个命题，条件为其组件；引出语（"佛告金剛藏菩薩"）单独成命题，类型 `frame`。切分在梵文侧完成，藏、汉侧只做对齐，不另切。

## 2 金标准是一个分布，不是一个文本

设梵文见证集合 \(S=\{s_1,\dots,s_k\}\)（校勘本＋写本＋注疏引文）。对单元 \(u\) 的组件 \(c\)，记

\[
p_{s_i}(c)\in\{1,0,\varnothing\}
\]

分别表示"该梵文见证有此组件 / 无此组件 / 该处脱叶或未收"。

- **共识** \(\bar p(c)=\text{majority}\{p_{s_i}(c): p_{s_i}(c)\neq\varnothing\}\)。
- **梵文内部方差** \(\sigma_S(u)=\) 单元内组件在各梵文见证间不一致的比例。这是行的属性，写入矩阵，用于把"金标准本身不稳的行"在统计中降权或分层。
- **可被证实的缺席** \(A_S(c)=\mathbb{1}[\exists i:\ p_{s_i}(c)=0]\)：至少一个梵文见证没有该组件。

任何译本见证 \(w\) 的偏移都同时对共识和对每个 \(s_i\) 计算（§4）。

## 3 单元格记录（L2）

```
Cell(u, w):
  status        PRESENT | PARTIAL | ABSENT | LACUNA | UNALIGNED | NA
  span          见证坐标（汉：卷/页栏行起止；藏：叶.行起止；梵：校勘本页行/偈号）
  bead          n:m（参照侧单元数 : 见证侧片段数）
  d_cov         覆盖度 ∈ [0,1]
  d_len         篇幅残差 ∈ ℝ
  d_lit         音译密度 ∈ [0,1]
  d_ord         位序位移 ∈ [0,1]
  d_split       结构改动 ∈ ℝ≥0
  d_comp        组件呈现向量（L3 聚合；可空）
  evidence      A | B | C | X（该格判定所依据的证据等级，定义沿用实验规划 §04）
  prior         该格差异是否已见于先行研究（鈴關 / Willemen / Isaacson / 德重）
  provenance    标注者、时间、模型版本、文件哈希
```

`status` 的语义：

- `PRESENT`：单元的核心命题在见证中可辨认（\(d_{cov}\ge 0.8\) 或人工判定）。
- `PARTIAL`：部分组件可辨认。
- `ABSENT`：在该品的对应范围内找不到任何组件；见证本身在此处**完好**（否则为 `LACUNA`）。
- `LACUNA`：见证物理缺损（脱叶、残破、校勘本标注 lacuna）。这是与 `ABSENT` 必须区分的状态。
- `UNALIGNED`：自动对齐未能判定、人工尚未复核。
- `NA`：该见证不覆盖该品（如注疏引文只覆盖被引偈）。

统计时 `LACUNA`、`UNALIGNED`、`NA` 都不进入分母。

## 4 偏移向量各维定义

以下 \(u\) 为参照单元，\(w\) 为见证，\(r\) 为参照（共识或某一 \(s_i\)）。

### 4.1 覆盖度 \(d_{cov}\)

有组件标注时：
\[
d_{cov}(u,w)=\frac{\#\{c\in C(u):\ p_w(c)\in\{1,\text{sub},\text{lit}\}\}}{|C(u)|}
\]
即"以任何方式呈现"（含替换、音译）的组件比例。省略率 \(1-d_{cov}\)。

无组件标注时由状态映射：PRESENT→1，PARTIAL→0.5，ABSENT→0。

### 4.2 篇幅残差 \(d_{len}\)

\[
d_{len}(u,w)=\log\frac{\ell_w(u)}{\ell_r(u)}-\widehat{\mu}_{w,\,g(u)}
\]
其中 \(\ell\) 为归一化长度（梵：音节；藏：音节；汉：字），\(\widehat{\mu}_{w,g}\) 是该见证在同一体裁 \(g\)（偈/散文）**中性单元**上的对数长度比中位数。这样 \(d_{len}\) 表示"比该译者对同体裁中性内容的常规译法更短/更长多少"，剔除了语言对本身的膨胀率。

### 4.3 音译密度 \(d_{lit}\)

\[
d_{lit}(u,w)=\frac{\#\text{content tokens rendered by transliteration}}{\#\text{content tokens}}
\]
实现：汉文以 `data/anchors/terms.yaml` 的 `zh_transliteration: true` 词条＋音译字集估计；藏文以梵文借词（含 ཱ 等长音符号或 Sanskrit-only 字母组合）估计。真言、尊名单列为控制层（`topic=mantra_control`），因为那里音译是常规而非遮蔽。

### 4.4 位序位移 \(d_{ord}\)

在品内，\(\rho_r(u)\) 为单元在参照中的归一化位置（0–1），\(\rho_w(u)\) 为其对齐片段在见证中的归一化位置：
\[
d_{ord}(u,w)=|\rho_w(u)-\rho_r(u)|
\]
品级则用 Kendall \(\tau\) 距离报告整体重排。

### 4.5 结构改动 \(d_{split}\)

对 bead \(n:m\)：\(d_{split}=\log(n\cdot m)\)，1:1 为 0；1:2、2:1 为 \(\log 2\)。

### 4.6 组件呈现向量 \(\mathbf{d}_{comp}\)

每个组件 \(c\) 在 \(w\) 中取值：

| 码 | 含义 | 举例（梵→汉）|
|---|---|---|
| `ret` | 保留 | śvānamāṃsa → 犬肉 |
| `gen` | 概括（上位词） | śvānamāṃsa → 肉 |
| `sub` | 替换（不同指称）| viṇmūtra → 世間供養 |
| `lit` | 音译不释 | bhaga → 婆倪 |
| `om`  | 省略 | — |
| `add` | 见证增写（只出现在孤儿行或 `extra` 组件）| — |

聚合：保留率 \(=\#ret/|C|\)，弱化率 \(=\#(gen+sub+om)/|C|\)，音译率 \(=\#lit/|C|\)。注意 **`gen`、`sub`、`om` 是形式描述，不是动机判断**；"委婉"不是码（《评估》§4.6）。

## 5 偏移的三分分解

对译本见证 \(w\)（如 `zh_T0892_song`）及其独立同源见证 \(w'\)（如 `bo_derge_D417_418`），在组件层：

\[
\underbrace{\mathbb{1}[p_w(c)\neq\text{ret}]}_{\text{总偏移}}
=\underbrace{A_S(c)}_{\text{Vorlage 可解释}}
+\underbrace{(1-A_S(c))\cdot\mathbb{1}[p_{w'}(c)\neq\text{ret}]}_{\text{与 }w'\text{ 共享}}
+\underbrace{(1-A_S(c))\cdot\mathbb{1}[p_{w'}(c)=\text{ret}]}_{\text{残余}}
\]

三项互斥且穷尽（在 \(p_w(c)\neq\text{ret}\) 的组件上）。按单元、按品、按主题聚合后得到三个率：

- **\(E_V(w)\)** Vorlage 可解释率：偏移中至少有一个梵文见证与 \(w\) 一致的比例。
- **\(E_S(w\mid w')\)** 共享率：梵文一致有、但 \(w\) 与 \(w'\) 同样不保留的比例。指向"共同的注疏传统或共同的失传 Vorlage"。
- **\(R(w\mid w')\)** 残余率：梵文各本皆有、\(w'\) 保留、只有 \(w\) 不保留。**只有这部分**才是关于译者/译场的任何讨论的合法输入。

无组件标注时在 L2 状态上做同样分解（\(\text{ret}\) 换成 `PRESENT`）。

这一分解是本项目相对先行研究的核心度量创新：它把"梵有汉无"从一个二值观察变成三个可分别报告、可分别检验的量。CATSS 的 `=` / `=?` / `=??` 是其人工先例，我们将其做成对全部单元机械可算的量。

## 6 主题分层（事后变量）

主题在梵文（或藏文）侧、**看汉文之前**由两人独立标定，取值：

`sexual` / `female_agent` / `flesh_food` / `harm` / `theft` / `impure_substance` / `bone_corpse` / `secret_practice` / `neutral` / `mantra_control` / `frame`

前八类与德重 2026 的 ①–⑧ 对应，以便结果可比；`mantra_control` 是音译密度的负控制；`frame` 为叙述框架句。主题不参与任何偏移计算，只用于分层报告和 §8 的匹配对照。

## 7 见证剖面与见证间距离

**剖面** \(\mathbf{P}(w)\)：按品 × 维度的均值矩阵（23 × 5，加组件维度时更多）。热图直接可视化。

**见证间距离**：在两见证都非 `LACUNA/UNALIGNED/NA` 的单元集合 \(U_{w_1w_2}\) 上，
\[
D(w_1,w_2)=\frac{1}{|U_{w_1w_2}|}\sum_{u}\Big[\lambda_0\,\mathbb{1}[\text{status}_{w_1}\neq\text{status}_{w_2}]+\sum_{k}\lambda_k\,|d_k(u,w_1)-d_k(u,w_2)|\Big]
\]
权重 \(\lambda\) 默认等权并预注册。对 \(D\) 做层次聚类与 neighbor-net。预期：派生见证（西夏文、蒙文、明译）与其来源列（藏）聚合；若否，则记录为发现。梵文各校勘本之间的 \(D\) 给出"金标准内部方差"的另一视图。

## 8 统计报告规范

1. **分母**：只用 `PRESENT/PARTIAL/ABSENT` 单元；报告 `LACUNA`、`UNALIGNED` 的数量。
2. **中性基线**：每个维度先报中性单元均值，再报各主题相对中性的**差值**，不报绝对值单独解读。
3. **匹配对照**：敏感单元与同品、同体裁、长度相近、专名密度相近的中性单元 1:1 匹配（贪心，预注册匹配规则）；主估计量 \(\Delta=R_{sens}-R_{neut}\)。
4. **不确定性**：按品区组自助法（23 个区组，1,000 次）给 95% 区间；品级置换检验作补充。**不做**跨作品推断。
5. **金标准不稳的行**：\(\sigma_S(u)>0\) 的单元单独分层报告；主结果同时给"含/不含"两种口径。
6. **先行例证**：`prior=true` 的单元单独计数，不并入"新发现"。
7. **零结果**：若 \(\Delta\) 区间含零，照实发表。

## 9 证据充分性与归因（E3）

对每个 `status ∈ {ABSENT, PARTIAL}` 或含 `sub/gen/om` 组件的单元格，程序先做**证据门**：

```
evidence_gate(u, w):
  if 任一梵文见证在 u 为 LACUNA 且其余梵文见证不足 2 列  → INSUFFICIENT
  if w' 在 u 为 LACUNA/UNALIGNED                            → INSUFFICIENT_COWITNESS
  else                                                       → SUFFICIENT
```

只有 `SUFFICIENT` 的单元格进入归因；归因输出是**多标签分布**，标签集合固定为：

`vorlage_attested`（某梵文见证同样缺/异）· `shared_with_cowitness`（藏同缺）· `lacuna`（物理缺损）· `unexplained_at_translation`（残余，不指认动机）· `abstain`

**不存在** `censorship` 标签。动机讨论只出现在论文的历史部分，且以 §5 的残余率为唯一输入。

### 9.1 LLM 过度归因反事实实验

固定一个 `ABSENT` 的汉文单元格，构造两种提示：

- 条件 A：只给汉文与一种梵文校勘本；
- 条件 B：另给出"某梵文写本 / 藏译在此处同样缺文"的事实。

记录模型输出中出现"删略 / 审查 / 自主规制 / 回避"等动机断言的比率 \(\pi_A,\pi_B\)。\(\pi_A-\pi_B\) 及区间即"过度归因幅度"。提示模板与判定规则在 `hevajra_matrix/attribution.py` 中固定并预注册。

## 10 输出文件

| 文件 | 内容 |
|---|---|
| `out/cells.csv` | L2 长表：一行一个 (u, w) 单元格 |
| `out/components.csv` | L3 长表：一行一个 (u, c, w) |
| `out/structure.csv` | L1：品 × 见证 |
| `out/wide_<dim>.csv` | 每个维度一张 单元 × 见证 宽表 |
| `out/profile_<w>.csv` | 见证剖面（品 × 维度）|
| `out/distance.csv` | 见证间距离矩阵 |

| `out/manifest.json` | 输入文件哈希、参数、代码版本 |

所有输出只含坐标、标签、数值与合理长度的短引文。
