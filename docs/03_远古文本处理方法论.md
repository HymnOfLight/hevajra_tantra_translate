# 见证矩阵法：多见证古代文本的计算处理方法论

版本 v0.1 · 从《喜金刚本续》项目提炼，面向任何"一个源文本、多种传抄与翻译"的古代文本

---

## 0 适用对象

一部文本 \(T\) 存在多个**见证**（witness）：同语言的不同写本或刻本、不同语言的译本、译本的再译本、注疏中的引文。研究者想回答的问题通常是：各见证离"原本"多远、朝哪个方向漂移、漂移是传承造成还是翻译造成、能否据此重建传承关系。典型对象：七十士译本与希伯来本、希腊–叙利亚–阿拉伯–拉丁科学翻译链、汉译佛典与梵藏本、敦煌写本与传世刻本、《老子》诸本。

本方法论的立场：**"原本"不可得，所能得到的是一组见证之间可测量的几何关系。** 所有结论都是关于见证之间的，不是关于原本的。

---

## 1 十条原则

1. **见证优先于文本**。研究单位是见证，不是"《喜金刚》"这个抽象物。每个见证有语言、年代、来源语言、独立性、物理状态，这些元数据参与全部统计。
2. **金标准是分布**。选定参照语言（通常是源语言）后，参照不是一本校勘本，而是该语言全部可用见证的集合；参照内部的不一致本身是要测量的量（`σ_S`）。
3. **缺席有四种**。缺失（ABSENT）、物理缺损（LACUNA）、未能判定（UNALIGNED）、不在覆盖范围（NA）必须是四个状态，混用任何两个都会造成系统性偏差。
4. **现象与原因分离**。单元格里只记录可观察的形式（保留/概括/替换/音译/省略/增写），原因（Vorlage 差异/共享/残余）由跨列比较**机械推导**，动机（审查/秘密/伦理）不进入数据，只进入论文的解释部分。
5. **从参照侧建行**。行标识来自参照语言的单元，而不是来自任何一个译本；否则译本整段缺失的地方没有入样概率。
6. **偏移相对于该见证自身的中性基线**。每个见证都有语言对和译者风格带来的常规膨胀、常规概括；报告的量是"相对同见证中性单元的超额"，不是绝对值。
7. **派生见证不是独立见证**。译自译本的见证（藏→西夏文、藏→明汉译）在统计上只能作为其来源列的检验，不能与来源列并列作为独立证据；但它们对方法检验极有价值："派生不增偏移"是可证伪的。
8. **现代译本只是桥梁**。用于检索、复核、加速人工，绝不进入偏移统计，绝不当作古代见证。
9. **小文本普查、大文本抽样，先算框再定量**。抽样框由参照侧单元数决定；配额超过可用单元数时抽样失去意义。
10. **可复算高于可解释**。每一个数都能由公开坐标、公开标签与开源代码重算出来；受版权文本不进入发布物，只发坐标。

## 2 流水线

```
W0 见证登记 ──► W1 结构对应 ──► W2 参照侧切分 ──► W3 对齐（含 NULL）
    │                 G0 签署            行标识              人工修正
    ▼
W4 组件标注（双盲）──► W5 矩阵装配 ──► W6 分解与统计 ──► W7 归因/弃判 ──► W8 发布
        α 关口              哈希锁定           预注册             证据门         只发坐标
```

| 步 | 输入 | 输出 | 关口 / 常见失败 |
|---|---|---|---|
| **W0 见证登记** | 目录、题记、先行研究 | `witnesses.yaml`：每列的语言/来源语言/年代/独立性/状态/许可 | 把修订本当初译本；把现代译本登记为古代见证；未核实就填编号 |
| **W1 结构对应** | 各见证的章/品/卷划分 | 章级概表，格位 status ∈ {proposed, verified, absent, merged, uncertain} | 依据题记或夹注反推"摘出边界"（《喜金刚》"略出"注的教训）；须由逐单元对齐确认 |
| **W2 参照侧切分** | 参照语言各见证 | 单元列表（偈/命题）＋ 行标识；参照内部方差 `σ_S` | 从译本侧切分 |
| **W3 对齐** | 单元列表 × 各见证文本 | 每格 status、span、bead | 不允许 NULL 的对齐器会把缺失"抹平"到相邻单元；必须品级门控、必须允许 0:1 / 1:0 |
| **W4 组件标注** | 对齐后的单元格 | 组件 × 见证的呈现码 | 标注员做整体"是否弱化"判断（预期偏差）；用带动机色彩的码（"委婉"）|
| **W5 矩阵装配** | W1–W4 | 三层矩阵 + manifest（哈希）| 覆写底本；不记录 provenance |
| **W6 分解与统计** | 矩阵 | 三分分解、中性基线差、区组自助法区间、见证距离与聚类 | 跨作品推断（n 太小）；在看结果后改主指标 |
| **W7 归因/弃判** | 矩阵 + 证据门 | 多标签分布；正确弃判计分；LLM 反事实实验 | 标签集含动机词；证据不足时不弃判 |
| **W8 发布** | 全部 | 坐标 + 标签 + 数值 + 代码；受限文本不发布 | 混合不兼容许可（BY-SA 与 BY-NC-SA；NC-ND 派生片段）|

## 3 最小度量集合（跨文本可迁移）

任何文本都能计算的五个结构维度 + 一个可选组件维度：

| 维度 | 需要什么 | 不需要什么 |
|---|---|---|
| \(d_{cov}\) 覆盖 | 对齐 | 语义标注 |
| \(d_{len}\) 篇幅残差 | 对齐 + 每语言长度归一化（音节/字）+ 中性单元集合 | — |
| \(d_{lit}\) 音译密度 | 目标语音译识别（字表或借词形态）| — |
| \(d_{ord}\) 位序 | 对齐 | — |
| \(d_{split}\) 结构 | 对齐 bead | — |
| \(\mathbf{d}_{comp}\) 组件 | 双盲组件标注 | — |

以及**三分分解** \(总偏移 = \text{Vorlage可解释} + \text{与同源见证共享} + \text{残余}\)，需要至少两个参照见证与至少一个独立同源译本。只有一个参照本时，分解退化为两项（共享 + 残余），报告时必须注明。

**中性基线**是唯一不可省略的统计设计：没有它，"某见证省略多"只能说明该语言对膨胀率不同。

## 4 谬误清单（在设计评审时逐条勾选）

- [ ] **单本真值**：用一个校勘本代表源语言。→ 登记 ≥ 2 参照列，报告 `σ_S`。
- [ ] **缺文即删略**：`ABSENT` 未与 `LACUNA`、Vorlage 异读区分。→ 四态状态 + 三分分解。
- [ ] **动机入数据**：标签集含"审查""委婉""回避"。→ 只保留形式码。
- [ ] **译本侧抽样**：从汉文/目标语抽样。→ 参照侧建行。
- [ ] **修订层混同**：把后世修订本当作初译（德格本《喜金刚》经 15 世纀补订）。→ 多列同语言见证，比对分离修订层。
- [ ] **派生当独立**：藏→西夏文当作独立于藏的证据。→ `independence: derived`，只作来源列检验。
- [ ] **现代译本当见证**：84000 / Snellgrove 英译进入统计。→ `layer: pivot`。
- [ ] **抽样超框**：小作品配额 > 可用单元。→ 普查。
- [ ] **跨作品 p 值**：n = 4 部作品做符号检验。→ 描述性报告 + 作品内区间。
- [ ] **看结果后改指标**：→ 预注册，锁定哈希。
- [ ] **LLM 记忆污染**：通用模型已读过现代译本与先行论文。→ 记忆探测；模型判断只作基线。
- [ ] **许可混合**：→ 数据管理计划，只发坐标。
- [ ] **依据题记反推结构**："略出"、"节译"类自述当作译者声明。→ 结构只由对齐确定。

## 5 人机分工

| 任务 | 机器 | 人 |
|---|---|---|
| 见证登记、哈希、坐标 | 全部 | 核对许可、年代依据 |
| 结构对应 | 提出 proposed | 逐单元核实并签署 |
| 切分 | 参照侧自动切 | 修正命题边界 |
| 对齐 | B0 锚点 + DP + NULL；可选嵌入 | 复核全部 NULL、全部 n:m、抽检 1:1 |
| 组件标注 | 预填候选（LLM 抽取，受词典约束）| 双盲定码；第三人裁决 |
| 度量与统计 | 全部 | 预注册；解释 |
| 归因 | 证据门 + 规则分布 | 复核 `unexplained_at_translation` 的每一例 |
| 历史解释 | 无 | 全部 |

原则：机器负责穷举与一致性，人负责边界与解释；任何机器输出都写入派生层，不覆写底本。

## 6 复现包规范

```
manifest.json     每个输入文件的来源 URL、取得日期、SHA-256、许可
witnesses.yaml    列定义
chapters.yaml     结构对应（含签署人与日期）
units.csv         行定义（参照侧）
cells.csv         L2
components.csv    L3
decomposition.csv 分解结果
distance.csv      见证距离
prereg.md         预注册文本及其哈希、解封日期
CHANGELOG.md      解封后每一次改动
```

不发布：任何见证全文（除许可允许的短引文）、现代译本片段、嵌入模型权重。

## 7 迁移到其他文本时要改什么

| 对象 | 参照语言 | 需替换的模块 | 需保留的模块 |
|---|---|---|---|
| 《密集》T0885 / Toh 442–443 / 松长本 / 敦煌 IOL Tib J 438 | 梵 | 见证清单、章表、锚点词表（施护译语）| 全部度量、分解、统计、归因 |
| 七十士译本 vs 马所拉本 vs 库姆兰 | 希伯来 | 切分（诗行/节）、音译识别（希腊语借词）| 同上；CATSS 的 =/=? 可直接映射到三分分解 |
| 盖伦希腊–叙利亚–阿拉伯 | 希腊 | 长度归一化（词而非音节）、锚点（专名、药名） | 同上；派生见证（叙→阿）检验尤其重要 |
| 《老子》诸本（郭店/马王堆/王弼/河上公）| 无源语言，选最早层为参照 | 参照为同语言多见证，`σ_S` 成为主要量 | 覆盖、位序、结构维度；组件层 |

改动集中在 W0–W2 与 `anchors`；W3 之后的模块与语言无关。这是方法论的可迁移性主张，也是方法论文的可检验命题：在《密集》上复跑同一流水线，报告需要改动的行数。
