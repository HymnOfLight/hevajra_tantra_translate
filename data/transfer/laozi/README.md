# 《老子》诸本迁移研究：数据目录

设计见 [`docs/05_迁移研究：老子诸本与候选文本.md`](../../../docs/05_迁移研究：老子诸本与候选文本.md)。

```
data/transfer/laozi/
├── witnesses.yaml    见证清单（列）；reference: true 的一列提供坐标系
├── concordance.yaml  郭店三组章序、马王堆章序说明（待核）
├── variants.yaml     异文归一表（避讳 / 通假 / 异体；虚词默认不归一）
├── README.md
└── texts/            研究者自备文本，.gitignore 排除
    ├── zh_wangbi.txt
    ├── zh_guodian_A.txt
    └── ...
```

## 文本文件格式

```
// 注释行
#19                 通行本第 19 章开始（文件中的出现次序 = 该见证自身的章序）
絕智棄辯，民利百倍。絕巧棄利，盜賊亡有。…
#64下 @甲簡10-13    半章标记；@ 后为该见证的原生坐标（简号 / 行号 / 页码），可省略
#1?                 章号判定不确定
道可道也，□恆道也。  □ 表示残缺字；一句中残缺字占比 ≥ 50% 的句子记为 LACUNA
```

- 句级切分按 `。？！，；：、` 自动进行；请保留标点（整理本标点即可，不必一致——标点不进入相似度）。
- 通行本（参照）文件必须完整；其他见证可以只含部分章（选编本未收之章自动记 `NA`）。

## 来源与许可

| 见证 | 建议来源 | 许可 |
|---|---|---|
| 王弼本、河上公本、傅奕本 | 维基文库（zh.wikisource.org）录文；或据楼宇烈《王弼集校释》自录 | 古籍原文公有领域；维基文库录文 CC BY-SA |
| 马王堆甲乙本 | 《马王堆汉墓帛书〔壹〕》（文物出版社 1980）、高明《帛书老子校注》（中华书局 1996）、裘锡圭主编《长沙马王堆汉墓简帛集成》（中华书局 2014） | 释文有版权：**只在本地使用，不入库**，仓库只发布坐标、标签与数值 |
| 郭店甲乙丙组 | 《郭店楚墓竹简》（文物出版社 1998）；刘钊《郭店楚简校释》（福建人民 2003） | 同上 |
| 北大汉简 | 《北京大学藏西汉竹书〔贰〕》（上海古籍 2012） | 同上 |
| 想尔注 S.6825 | 饶宗颐《老子想尔注校证》；IDP 图版 | 释文有版权 |
| 韩非子、淮南子引文 | 维基文库 / CText 录文，按所释章手工标 `#N` | 公有领域 |

宽式释文与严式释文的选择必须在 `manifest.json` 中记录（`inputs` 的 SHA-256 已自动记录）；本仓库的度量默认基于**宽式**释文（已破读为通行字），因为 `variants.yaml` 只处理常见对应，严式释文会把大量楚文字字形差异算进 `d_lex`。若使用严式释文，请把 `variants.yaml` 扩充到该释文的字表并在预注册中声明。

## 运行

```bash
python -m hevajra_matrix transfer --config data/transfer/laozi --texts data/transfer/laozi/texts --out out/laozi
```

输出与主流水线同构：`cells.csv`、`structure.csv`、`wide_*.csv`、`alignment_review.csv`（多 `d_lex_raw` 与 `variants_explained` 两列）、`chapter_order.csv`、`heatmap_*.svg`、`summary.md`、`manifest.json`。`tests/fixtures/laozi/` 中的三章示例文本仅供测试流水线，不是学术释文。
